# WaterGeo source portfolio

**Reviewed: 28 September 2026.** “Implemented” means the repository contains a
governed product contract. It does not mean a persistent public WaterGeo database is
running. No hosted production database is currently active.

The three existing scheduled workflows are implemented in GitHub Actions, but their
schedule jobs run only when their named repository variable is exactly `true`.
Manual dispatch is independent of that gate. No variables are enabled by this phase.
