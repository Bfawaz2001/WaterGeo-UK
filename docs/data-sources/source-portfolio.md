# WaterGeo source portfolio

**Reviewed: 10 October 2026.** “Implemented” means the repository contains a governed
product contract. The accepted ten-source static snapshot is published through GitHub
Pages; it is not a persistent public WaterGeo database or live feed. No hosted public
FastAPI/PostGIS service is currently active.

The six refresh workflows are implemented in GitHub Actions, but their
schedule jobs run only when their named repository variable is exactly `true`.
Manual dispatch is independent of that gate. Repository variables and external
database availability determine whether scheduled refreshes actually run; these
cadences do not make the static Pages publication live.
